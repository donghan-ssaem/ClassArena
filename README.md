# 교실 아레나 (두리·서이)

QR로 들어와서 함께 즐기는 실시간 퀴즈·미니게임 웹앱입니다.

- 관리자 페이지: `/admin` (노트북으로 열어 프로젝터에 띄움)
- 참가자 페이지: `/play` (폰, 크롬북) — QR을 찍으면 참가 코드가 자동으로 들어감
- 한 방에 기본 50명, 관리자 화면에서 80명까지 늘릴 수 있음

## 게임과 점수

| 게임 | 방식 | 점수 |
|---|---|---|
| 퀴즈 | 다 같이 한 문제씩. 가장 먼저 맞힌 1명이 나오면 바로 멈추고 발표. 틀리면 1.5초 뒤 재도전 | 누적 점수와 별개 (문제별 1등 정답자 명단·CSV) |
| 달리기 | 왼발·오른발 버튼 번갈아 연타. 먼저 도착한 순 | 1등 50점, n등 51−n점 |
| 10초를 멈춰라 | 시계가 3초 뒤 사라짐. 10.00초에 가까운 순 | 〃 |
| 문질문질 | 정해진 시간 동안 좌우로 문지른 횟수 | 〃 |

- 동점은 같은 등수·같은 점수, 참여하지 않으면 0점입니다.
- 51등 이하(인원을 50명보다 늘린 경우)는 1점입니다.
- 크롬북은 달리기에서 ← → 또는 F J 키, 문질문질에서 마우스 드래그나 ← → 키로도 할 수 있습니다.

## 퀴즈 문제 넣기 (구글 시트)

1. 구글 시트를 새로 만들고, 같이 들어 있는 `퀴즈_시트_양식.csv`를 [파일 > 가져오기]로 불러오거나 아래 열 순서대로 적습니다.
   `문제 | 안내문 | 정답 | 보기1 | 보기2 | 보기3 | 보기4 | 다른 정답`
   - 보기를 모두 비우면 **주관식**입니다. 띄어쓰기·대소문자는 무시하고 채점하며, 다른 정답은 쉼표로 여러 개 적을 수 있습니다.
   - 보기를 적으면 **객관식**입니다. 정답 칸에는 보기 글자 그대로 또는 번호(1~4)를 적습니다.
   - 퀴즈 하나당 탭 하나로 나눠 쓰면 됩니다 (예: '보드게임 초성' 탭, '연구회 1년 정리' 탭).
2. 오른쪽 위 [공유] → 일반 액세스를 **링크가 있는 모든 사용자 · 뷰어**로 바꿉니다.
3. 불러올 탭을 연 상태에서 주소창의 주소를 복사해 관리자 화면 [문제 불러오기]에 붙여넣습니다.
4. 시트가 안 불러와지면 시트에서 칸을 선택해 복사한 뒤 [붙여넣기]로 넣어도 됩니다.

## 내 노트북에서 먼저 실행해 보기

1. 압축을 푼 `classarena` 폴더를 VS Code로 엽니다 ([파일 > 폴더 열기]).
2. VS Code 위쪽 메뉴 [터미널 > 새 터미널]을 엽니다. 터미널 경로가 `...\classarena`로 끝나는지 확인합니다.
3. 처음 한 번만 입력: `npm install`
4. 실행: `npm start`
5. 크롬에서 `http://localhost:3000/admin`을 엽니다. 같은 노트북의 다른 크롬 창에서 `http://localhost:3000/play`로 참가해 볼 수 있습니다.
   (폰으로 QR을 찍어 들어오는 건 아래처럼 인터넷에 올린 뒤에 됩니다.)
6. 끄려면 터미널에서 `Ctrl + C`

## 무료로 인터넷에 올리기 (Render, 싱가포르 서버)

1. GitHub에서 새 저장소(예: `classarena`)를 만들고 이 폴더의 파일을 모두 올립니다 (`node_modules` 폴더는 빼도 됩니다).
2. https://render.com 에 GitHub 계정으로 가입합니다.
3. [New +] → [Blueprint] → 방금 만든 저장소 선택 → [Apply]
   - 저장소에 든 `render.yaml`이 지역(싱가포르), 무료 플랜, 실행 명령을 자동으로 설정합니다.
   - Blueprint가 안 보이면 [New +] → [Web Service]로 만들고 Region: Singapore, Build Command: `npm install --omit=dev`, Start Command: `npm start`, Instance Type: Free로 직접 고릅니다.
4. 배포가 끝나면 `https://이름.onrender.com` 주소가 생깁니다. 관리자는 `https://이름.onrender.com/admin`
5. 코드를 고쳐 GitHub에 올리면 자동으로 다시 배포됩니다.

### 무료 서버 주의점
- 15분 동안 아무도 접속하지 않으면 서버가 잠듭니다. 깨어나는 데 1분 정도 걸리니 **수업 시작 5분 전에 관리자 화면을 먼저 열어 두세요.**
- 서버가 다시 시작되면(재배포, 잠들었다 깨어남) 진행 중이던 방과 점수는 사라집니다. 결과는 게임이 끝날 때마다 CSV로 저장해 두세요.
- 무료 서버는 CPU가 작습니다. 80명 테스트에서 퀴즈·미니게임 중 사용량은 한도의 절반 아래였지만, 처음 쓰기 전에 실제 폰 몇 대로 한 번 시험해 보세요.

## 파일 구성
- `server.js` : 방, 입장, 퀴즈 진행, 미니게임 진행, 점수 계산
- `lib/minigames.js` : 미니게임 규칙 (새 게임은 여기에 하나 추가)
- `lib/sheet.js` : 구글 시트 읽기
- `public/admin.html` : 관리자 화면 / `public/play.html` : 참가자 화면 / `public/img/` : 두리·서이 표정 이미지
- `test/load.js` : 80명 동시접속 시험 (`npm test`, VS Code 터미널에서 `classarena` 폴더 기준)
